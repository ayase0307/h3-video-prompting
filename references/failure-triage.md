# 失敗分診：症狀 → 原因 → 最小修正

彙整自 aireiter 社群回報整理、reAPI、AI-KSK failure-repair-matrix、MiniMax 官方飛書手冊評論區回覆、Runware 指南。

| 症狀 | 常見原因 | 第一步修 | 第二步修 | 不要做 |
|---|---|---|---|---|
| 畫面靜態、像海報 | 只描述外觀沒描述變化 | 加一個物理動作 + 結尾狀態 | 加時間軸 | 堆形容詞 |
| 動作糊成一團、沒做完 | 動作過載、沒有順序詞 | 一個 shot 一個主動作 | 加 first/then/as | 加更多細節 |
| 鏡頭亂飄 | 多個運鏡競爭 | 保留一個主運鏡 | 減少切鏡 | orbit+zoom+pan 疊加 |
| 全身走路被裁掉 | 用結果描述而非鏡頭指令 | `The camera pulls out with large amplitude at the same speed as the subject walks forward, maintaining a full-body composition.` | | 寫「entire subject remains visible」 |
| 節奏鬆、幻燈片感 | 沒切時間、shot 太長 | 拆成有時間戳的 shot | 每個 cut 帶新資訊 | 平均分秒數 |
| timestamp 太密、動作沒完成 | shot < 2 s、對白塞不下 | 合併 shot 或拉長 | 砍台詞 | |
| 慢動作抖動閃爍 | 背景高熵 | 簡化環境（雨→毛毛雨） | 慢動作獨立 shot | 再加形容詞 |
| 整支片都是慢動作／飄浮感（非刻意慢動作 shot） | ①薄 prompt ＋ 長時長（一件事撐滿秒數，模型只好拉長）②降步數本地加速（Turbo/蒸餾 LoRA）本身就會飄 | 提高事件密度：5 秒 3 beats，每段用 `[0 to 1.5s]` 切時間戳，動作內加變化（推鏡／光移／有人入畫） | 仍不夠就換引擎：base 全步數，或改 PDD Acc 8-step LoRA（`MiniMax-H3-FL2VA/Ref2VA-Acc-8Step`） | 只寫「normal speed」；把 10 秒塞一件事 |
| 皮膚蠟感／塑膠感（近景最明顯） | 高頻細節在低解析訓練 bucket 就丟了；商業打光詞與磨皮詞加成 | 加固定皮膚描述句（見 `skin-realism-block.md`）＋ medium/close shot 給模型更多臉部資訊 | 疊 fal `MiniMax-H3-Realism-People-LoRA`（prompt 以 `r34l1sm` 開頭，strength 0.65），或後期用 H3 Skin Finish 類節點（只動 mask 內膚色/油光） | 上 beauty filter 或無腦 upscaler（會把紋理一起磨掉） |
| 加了音樂（寫了 N/A 仍有） | 約 20% 漏；文中有「氛圍音樂」字眼 | 全文移除任何音樂情緒詞 | 重抽 | |
| 亂語 / 隨機台詞 | 沒安排動作、看鏡頭 | 正向寫「全程安靜、嘴閉合」+ 持續動作 | 改側臉/中遠景 | 用引號或台詞格式 |
| 錯的人說話 | speaker 沒綁到畫面內角色 | 明寫 (S1) 是畫面內哪個角色 | 音頻參考與 speaker 分開標 | 把 S ID 給 Audio 資產 |
| 畫內台詞變畫外音 | 缺 lip-sync 關聯 | 寫「visible on screen and says」 | 真畫外音才加「lips remain closed」 | |
| `<d>` 產生多餘人聲 | tag 路徑不穩 | 同句改純引號重試 | | 重寫整段 |
| 音頻參考被忽略 | 超過 3 段/15 s 或沒指派角色 | 每段給一個職責 | 剪短 | |
| 字幕跑出來 | 對白字數多 | 不要在 prompt 寫「不要字幕」 | 減少台詞、後期 | 反覆寫禁止字幕 |
| 文字亂碼 | 沒把字打出來 | 逐字加引號 + `do not misspell, do not add other text` | 品牌字改用圖片參考 | 只寫「HUD elements」 |
| 臉漂移 | 參考沒分工；臉太小 | 一張圖鎖身份，點名不變特徵 | 換中景/特寫 | 每個 shot 重述外觀 |
| 服裝變 | 沒鎖 | 明寫服裝清單 | 分開服裝參考 | 只寫「same clothes」 |
| 產品變形 | 幾何沒鎖 | 寫輪廓、部件數、標籤位置 | 減少透視變化 | 讓產品做變形動作 |
| FL2VA 沒到尾幀 | 首尾圖矛盾或動作過載 | 先修圖（同房間同機位同光） | 單一 shot、描述中間路徑 | 兩段靜態描述 |
| 首尾同圖做循環但尾幀變了 | 模型會補動作 | 描述回到原姿勢的路徑 | 後期裁切 | |
| 2D 動畫背景突然變暗 / 聚光燈 | 光照負向詞觸發 | 刪「壓低背景、聚焦暗化」等負向詞 | 保留「人物與背景曝光統一、亮度穩定」正向約束 | |
| 編輯改太多 | 沒鎖未點名內容 | `嚴格復現視頻1…只做以下變化：…其餘保持不變` | 逐條列最終狀態 | 重寫整場 |
| 中文台詞不出聲（本地） | tokenizer / 編碼 | 用 repo tokenizer | `<d>[Chinese] …</d>` | 改 prompt |
| >15 s 單鏡崩 | 超出設計範圍 | 拆 15 s 段落 | 尾幀接首幀 | |
| 動作遷移到動物/不同體型漂 | 形狀差太多 | 換相近體型參考 | 縮小遷移範圍 | |
| 參考影片的聲音跑進來 | 影片自帶音軌 | 換匹配聲線的參考 | Sound 句明寫想要的聲音 | |
| 中途換成另一個人（照片動畫） | 代名詞/角色/場景與照片不符 | 全文代名詞與職業對齊照片 | 不描述第二個人 | |
| 最後一個 shot 呆住（dead air） | 對白擠在 shot 開頭，結尾沒動作 | 每個 shot 給一個收尾動作 | 縮短 shot | |
| 嘴巴橡皮化、過度張口 | 沒約束口型 | `realistic lip articulation, no exaggerated mouth opening` | `locked camera, no head turns while speaking` | |
| 動作遷移後原演員仍殘留 | 影片同時控制身份 | 明寫 Video 1 只負責動作，不複製演員/服裝/場景 | 兩段式：先換人再換背景 | 一次換人+換景+精細手部 |
| 運鏡被忽略 | 詞不在官方 20 種內或沒落點 | 用官方詞 + 落點 | 先 static 重跑再加回 | 自創「camera moves left」 |
| 幻燈片感（多圖輪播） | 圖之間沒有因果橋 | 上一鏡末動作接下一鏡首動作 | 減少圖片數 | 每張圖各自一段靜態描述 |
| 手指細節壞 | 精細操作是弱項 | 改中景、縮短時間 | 用參考影片遷移 | 慢動作特寫手指 |
| 2D 變 3D 混血 | 只寫「anime style」 | 參考圖錨定 + 描述繪製方式 | 刪 volumetric/DOF 詞 | 每個 prompt 重述角色外觀 |

## 送出前 8 問（reAPI）

1. clip 期間什麼在變？
2. 最後一秒必須成立什麼？
3. 鏡頭在做什麼？
4. 哪些視覺細節被保護？
5. 誰說話、說什麼原文？
6. 應該聽到什麼環境聲與音效？
7. 哪些聲音、切鏡、文字、logo 不能出現？
8. 每個參考素材各自唯一的職責是什麼？

兩個答案互相矛盾，先修 brief 再加時長或素材。

## 成本策略（atlascloud）

- 5 秒迭代，10/15 秒交付；構圖、色板、聲音設計在 5 秒就看得出來。
- end_image / 尾幀是省錢工具：多數重抽是因為結尾漂了。
- 負向清單與逐字文字不加成本（按秒計費），可以放心寫。
